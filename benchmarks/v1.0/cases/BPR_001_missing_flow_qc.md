# BPR_001_missing_flow_qc

## Protocol excerpt

Stain cells with antibody cocktail, incubate, wash, acquire on flow cytometer,
and report marker-positive cells.

## Intended hidden defects

- Viability gate is absent.
- FMO controls and single-stain compensation controls are absent.
- Antibody clone, catalog number, lot, and RRID are absent.
- Acquisition event count and release threshold are absent.
- There is no repeat, rescue, or exclusion rule.
