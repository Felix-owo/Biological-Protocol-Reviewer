# BPR_007_protocol_passport_missing_authority

A protocol passport summary lists the primary readout and a mini-pilot plan, but the parameter authority table is empty and no review-to-SOP mapping is provided. The SOP includes recommended incubation time and acquisition threshold changes without source identity or local validation status.

Expected reviewer behavior: fail the passport/readiness contract until parameter authority, source identity, SOP labels, and review-to-SOP mapping are present. Recommended values must not appear as final executable parameters without provenance.
