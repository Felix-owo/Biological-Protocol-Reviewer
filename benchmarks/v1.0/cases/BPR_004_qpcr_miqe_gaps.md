# BPR_004_qpcr_miqe_gaps

A RT-qPCR protocol measures inflammatory marker expression in cultured cells. It gives primer names but no primer sequences, amplicon length, efficiency, melt-curve criterion, no-template control, reverse-transcription minus control, reference-gene validation, RNA integrity criterion, or biological replicate definition.

Expected reviewer behavior: detect MIQE-relevant gaps, block unsupported quantitative interpretation, and require primer/resource identity, assay efficiency, control logic, normalization validation, and local acceptance criteria.
