# Input protocol fixture: missing flow QC

Stain samples with antibody mix, wash once, run on the cytometer, and analyze
the positive population.

Known gaps intentionally present in this fixture:

- No viability gate.
- No FMO or single-stain controls.
- No antibody clone, catalog number, lot, or RRID.
- No acquisition event count threshold.
- No exclusion or repeat rule.
