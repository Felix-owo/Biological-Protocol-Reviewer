# Biological-Protocol-Reviewer v1.1.2

This release makes the revised protocol output Markdown-first.

## Changes

- Default outputs are now `Review_Report.md` and `Revised_Protocol.md`.
- Removed DOCX rendering and office-suite visual QA from the default workflow.
- Renamed the revised protocol structure template to `templates/Revised_Protocol_md_structure.md`.
- Replaced the DOCX style profile with `references/markdown_sop_style.md`.
- Updated `protocol_output_validator.py` to validate Markdown SOP files with `--protocol`.
- Preserved SOP rigor: execution steps, reagent setup, resource tables, QC gates, troubleshooting, anticipated results, data analysis, and audit-ready appendices remain required.
