# User-Supplied Protocol Corpus Policy

Use when the user provides SOPs, vendor manuals, core-facility documents, lab
notes, antibody datasheets, primer sheets, sequencing specifications, analysis
scripts, prior revisions, figures, QC sheets, or local validation records.

## Corpus-first rules

1. Screen user-supplied materials before external recommendations.
2. Do not silently replace local protocol context with generic published
   parameters.
3. Do not modify the user's source corpus unless explicitly asked.
4. External search fills gaps, benchmarks choices, and resolves source identity;
   it does not erase supplied local validation.
5. If local and external sources conflict, document the conflict and decide based
   on readout risk, source quality, recency, and local validation.

## Exclusion log

Skipped supplied items must be listed with one reason:

- inaccessible or unreadable;
- duplicate;
- superseded by a newer supplied version;
- irrelevant to the protocol's intended result or primary readout;
- insufficient source identity;
- unsafe/confidential for a requested networked companion;
- low authority but retained as context.
