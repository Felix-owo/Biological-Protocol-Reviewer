# Frontier method modules

Activate these modules in addition to the base modules when the source protocol implies them. If the protocol is ambiguous, mark the module `Unclear — needs confirmation` and add the missing information to the assumption ledger.

| Module | Activate if protocol contains | Required controls and QC | Required metadata |
|---|---|---|---|
| CRISPR and genome editing | Cas9, Cas12, base editor, prime editor, gRNA, sgRNA, HDR, NHEJ, knock-in, knockout, pooled screen | non-targeting control, positive editing control, editing-efficiency assay, off-target risk discussion, viability/growth control, clone/genotype confirmation when relevant | editor, guide sequence/source, delivery method, MOI or dose, repair template, target locus, genome build, validation assay |
| Perturb-seq and pooled screens | perturb-seq, CROP-seq, CRISPR screen, pooled library, barcode, guide capture | library representation, MOI, guide distribution, cell number per guide, sequencing saturation, guide assignment QC, batch/blocking plan | library ID, guide annotation, barcode structure, read structure, demultiplexing method, reference version |
| Viral vector and delivery | lentivirus, AAV, retrovirus, adenovirus, pseudotype, transduction, viral titer | titer method, MOI/dose justification, transduction efficiency, replication-competent virus policy if relevant, containment and decontamination | vector map, serotype/pseudotype, promoter, cargo, packaging system, titer units, lot, biosafety approval |
| Organoid, co-culture, and spatial models | organoid, spheroid, co-culture, matrix, Matrigel, feeder, air-liquid interface | passage/window definition, size/viability morphology QC, matrix lot control, media-change timing, contamination and differentiation markers | source, passage, matrix lot, seeding density, culture geometry, media components, imaging/readout settings |
| Single-cell and multiome | scRNA-seq, scATAC-seq, multiome, CITE-seq, hashing, UMI, cell barcode | viability, doublet rate, input cell concentration, capture chemistry version, library size distribution, sequencing depth, saturation | chemistry kit/version, index/barcode plan, read structure, reference build, cell-calling software/version |
| Spatial omics | Visium, Xenium, MERFISH, CosMx, spatial transcriptomics, spatial proteomics | tissue integrity, section thickness, fixation, permeabilization, imaging QC, registration QC, negative/positive probes | tissue block, section ID, orientation, imaging settings, probe panel, segmentation software/version |
| Proteomics and metabolomics | LC-MS, MS/MS, TMT, DIA, DDA, metabolomics, lipidomics | internal standards, blank/QC injections, carryover, retention time stability, missingness, batch order | instrument method, column, gradient, acquisition mode, database/library, search settings |
| High-content imaging | high-content, automated microscopy, plate imaging, segmentation, image analysis | plate layout, focus/exposure QC, flat-field correction, segmentation validation, positive/negative control wells | objective, NA, channel settings, exposure, z-step, analysis pipeline/version |
| Animal surgery and behavior | surgery, implantation, cannula, telemetry, behavioral assay, maze, motor/cognitive test | analgesia/anesthesia, asepsis, recovery score, humane endpoints, randomization/blinding, acclimation, apparatus calibration | strain, sex, age, weight, housing, surgeon, anesthesia, analgesia, apparatus, scoring method |

For every activated frontier module, include a mini-pilot or local validation plan if the method is newly introduced, scaled, transferred between operators/facilities, or dependent on a new reagent/instrument version.
