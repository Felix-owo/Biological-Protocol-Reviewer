# SOP Rewrite Standards

A revised SOP must be structured as an auditable document, not a narrative note.

## Required sections

1. Document control: title, version, date, author, reviewer, approval, change log.
2. Bench-facing execution summary.
3. Before-you-begin checklist.
4. Step-by-step procedure.
5. Reagent preparation.
6. Reagents, consumables, equipment, software, primers/oligos, antibodies/probes.
7. QC checkpoints and acceptance criteria.
8. Timing and pause points.
9. Troubleshooting.
10. Expected outcome.
11. Data acquisition and analysis.
12. Appendices for purpose/scope, biological rationale, safety/governance, design, statistics, record sheets, reporting checklist, references, assumptions, and verification items.

## Style rules

- Use numbered steps for operations.
- Use tables for reagents, controls, QC, troubleshooting, and records.
- Mark unknown but required items as `待确认`.
- Do not invent values.
- For each QC threshold, specify action if failed.
- For each control, specify what artifact it detects.
- Keep long rationale and audit records out of the main bench procedure unless they are required during execution.
