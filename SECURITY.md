# Security Policy

## Supported Versions

The `main` branch and the latest GitHub release are supported for security and
package-integrity fixes.

## Reporting

Report security issues privately through GitHub Security Advisories when
available, or by opening a minimal issue that does not disclose private
protocols, credentials, unpublished data, or exploit details.

## Data Boundaries

This skill is local-first. Do not send confidential protocols, unpublished
experimental details, local file paths, credentials, or controlled biological
information to networked services unless the user explicitly approves that
transfer.

Companion tools and MCP outputs are evidence-discovery inputs only. They do not
override local validation, safety/governance review, parameter authority, or SOP
readiness judgment.
